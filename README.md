# SauceDemo E-Commerce QA Test Suite & Bug Reports

##  Project Overview
This repository contains a comprehensive manual Quality Assurance (QA) test suite and defect report for the **SauceDemo** e-commerce application, focusing on the `error_user` profile behavior.

##  Repository Contents
- **Test Cases Sheet (`.xlsx`):** Detailed test execution matrix covering Authentication, Catalog Navigation, Cart Management, Checkout Validation, and System State Persistence.
- **Bug Reports Document (`.docx` / `.pdf`):** Standardized defect logs including reproduction steps, severity/priority ratings, expected vs. actual outcomes, and visual attachments.
- **Screenshots:** Visual evidence capturing system anomalies and UI bugs.

## Testing Scope & Key Defect Areas Identified
- **Products & Cart:** Unresponsive "Add to Cart" and "Remove" action buttons.
- **Sorting:** Catalog sorting failure and system error alerts.
- **Checkout:** Field-clearing validation bug on the Last Name input field.
- **Navigation:** Session termination upon clicking "All Items" link.
- **Dynamic Catalog:** UI item duplication and full page reloads.

##  Tools Used
- **Test Management:** Microsoft Excel / Google Sheets
- **Bug Reporting:** Microsoft Word / Google Docs
- **Version Control & Portfolio:** GitHub
